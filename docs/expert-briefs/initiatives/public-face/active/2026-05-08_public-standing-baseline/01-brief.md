# Expert Brief - Public Standing Baseline

**Date:** 2026-05-08
**Initiative:** `public-face`
**Status:** active sprint
**Audience:** orchestrator or docs-capable implementer

## Why This Sprint Exists

iHomeNerd now has a standing review protocol, and the root/staging alignment
sprint has been promoted to `main`. Before the next public-face work starts,
capture a dated baseline that shows what outsiders would infer from:

- live root domain
- live staging domain
- promoted repo README and landing source
- public GitHub metadata
- crawl basics

## Product Goal

After this sprint, public-face work has a measurable baseline with:

1. input snapshot
2. panel response summary
3. scorecard
4. wrong-inference log
5. synthesis and next actions

## Required Scope

Complete the baseline folder:

```text
docs/public-face/reviews/2026-05-07_baseline/
```

Use the fixed review protocol and explicitly separate promoted source state
from live public deployment state.

## Out Of Scope

- product code changes
- README copy changes
- root/staging deployment
- GitHub settings
- license decision
- screenshots or generated assets

## Done Means

- baseline artifacts exist and are internally consistent
- scorecard explains each score with evidence
- wrong-inference log marks open, improved, resolved, or accepted items
- synthesis names the top three next public-face actions
