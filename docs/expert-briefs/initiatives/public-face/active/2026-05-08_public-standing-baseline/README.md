# Public Standing Baseline

## Goal

Complete the first repeatable public standing review using the protocol added
by the public-face foundation work.

## Why This Sprint Exists

The root/staging story-alignment sprint improved repo-controlled source, but
the public face needs a dated measurement artifact that separates:

- promoted source state
- live root page state
- live staging page state
- GitHub trust metadata state

## Scope

- run the public standing protocol
- complete the baseline review folder
- record scorecard, panel responses, wrong inferences, and synthesis
- update public-face sprint/testing indexes

## Out Of Scope

- changing landing code
- changing root deployment
- changing GitHub settings
- choosing a license
- adding screenshots or social images
