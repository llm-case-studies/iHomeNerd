# Public Face Foundation

## Goal

Create the initiative scaffold and durable knowledge base for iHomeNerd's
public-face work so that future website, GitHub, SEO, and trust-surface changes
have one place to start.

## Why This Sprint Exists

The 2026-05-07 public-face review showed that iHomeNerd has real product
substance but an inconsistent outward story:

- root domain and staging page tell different stories
- external AI summaries are drifting
- GitHub is active but under-signaled
- licensing/opening language is unclear

This sprint turns that ad hoc research into a working initiative.

## Scope

- create `docs/public-face/`
- capture thread research and audit findings
- define the first prioritized workstreams
- create `public-face` initiative and testing mirrors

## Out Of Scope

- landing-page redesign
- root-page implementation changes
- GitHub setting mutations
- SEO implementation
- licensing decision itself
