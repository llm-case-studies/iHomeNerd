# Round 1 Kickoff: Blind First-Pass Review

Use this for the first wave of reviewers.

The goal of Round 1 is to collect **independent takes** before reviewers are
influenced by one another.

---

Work in the discussion pack for:

- `discussion/uniform-web-ui-client-surface-boundary-review`

Start by reading only:

1. `README.md`
2. `01-seed.md`
3. `04-portfolio-working-list.md`
4. `02-feedback-template.md`

This is a discussion-only sprint.

Do not:

- write code
- propose tests
- edit implementation branches
- read or rely on other reviewers' responses if they already exist

Your job in this round:

1. react independently to the current framing
2. identify category mistakes, hidden assumptions, and route-boundary leakage
3. classify products, helper surfaces, and likely core primitives
4. preserve useful uncertainty instead of trying to smooth everything over

Please leave:

1. one structured response using `02-feedback-template.md` or equivalent
2. at least 2-3 concrete classification recommendations
3. at least one disagreement, tension, or uncertainty worth preserving
4. optionally, one candidate follow-on coding/testing sprint

Important:

- treat the current pack as a strong draft, not a finished doctrine
- prefer concrete route/capability examples over abstract commentary
- do not assume every useful helper should become a stable public iHN route

Desired Round 1 outcome:

- several independent viewpoints
- visible disagreement where the boundary is still fuzzy
- better raw material for synthesis in Round 2
