# Android Node Core Initiative

This initiative tracks Android-specific iHN core work that is already certain
enough to run while broader product-boundary discussions continue elsewhere.

These are not “maybe someday” ideas. They are practical gaps surfaced by the
recent Android bench work:

- ambiguous APK provenance across devices
- unclear mDNS / NSD registration behavior, especially on newer Android builds

Both are core-platform concerns, not app-specific helpers.
