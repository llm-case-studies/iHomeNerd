# Public Face

This folder is the durable home for iHomeNerd's outward-facing research,
audits, messaging decisions, and launch-surface work.

Use it for facts and decisions that should outlive any one sprint:

- what outsiders currently see
- what search and AI summaries are inferring
- where the website, staging surface, and GitHub repo disagree
- what trust, licensing, and discoverability gaps still exist
- which public-face workstreams matter next

Use `docs/expert-briefs/initiatives/public-face/` for active sprint packs and
execution handoffs.

## Seed Context

This lane was seeded on 2026-05-07 from a public-face review thread that
combined:

- live inspection of `ihomenerd.com` and `staging.ihomenerd.com`
- repo inspection of `iHomeNerd`
- public GitHub metadata review
- two external AI summaries: one from Google AI mode and one anonymous ChatGPT
  conversation

## Operating Rules

- Prefer dated notes over undated opinion.
- Record the exact public surface that caused a misunderstanding.
- Distinguish observed facts from interpretation.
- Keep the product story, trust story, and repo story aligned.
