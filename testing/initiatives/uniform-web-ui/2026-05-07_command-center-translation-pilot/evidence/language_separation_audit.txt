1. document.documentElement.lang
--------------------------------
Source: frontend/src/lib/languageUtils.ts (line 26, 32)
Mechanism:
  - setDocumentLang(code): sets document.documentElement.lang = code
  - persistLanguage(code): calls setDocumentLang + localStorage.setItem
  - initLanguagePersistence(): calls resolveInitialLanguage(), sets initial lang,
    listens to 'languageChanged' event to persist
  - resolveInitialLanguage(): checks ?lng URL param first, then localStorage,
    then DEFAULT_UI_LANGUAGE ('en')

but code audit confirms correct implementation)
