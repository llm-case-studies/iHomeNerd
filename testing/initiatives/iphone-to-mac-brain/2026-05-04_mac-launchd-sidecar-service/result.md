## Summary

Hardened all three launchd agent plists generated by
`install-ihomenerd-macos.sh` with production-ready configuration. Added
EXIT trap to `run-mlx.sh` for crash diagnostics.

## Plist Changes

| Agent | ThrottleInterval | ExitTimeOut | ProcessType | Nice | WorkingDirectory | NumberOfFiles |
|---|---|---|---|---|---|---|
| `com.ihomenerd.brain` | 10 | 15 | Standard | — | `${INSTALL_DIR}/backend` | 4096 |
| `com.ihomenerd.mlx` | 15 | 20 | Background | 5 | `${INSTALL_DIR}/runtime` | 4096 |
| `com.ihomenerd.ollama` | 10 | 15 | Background | — | `${INSTALL_DIR}` | 4096 |

### Common additions to all three plists

- **`KeepAlive`** — Changed from bare `<true/>` to dict form with
  `SuccessfulExit` and `Crashed` both `true` (restart on any exit,
  unlike `SuccessfulExit=false` which would leave the service stopped
  after a clean shutdown).
- **`ThrottleInterval`** — Prevents restart storms: 10 s for brain/Ollama,
  15 s for MLX (model loading is expensive).
- **`ExitTimeOut`** — Graceful shutdown window before SIGKILL: 15 s for
  brain/Ollama, 20 s for MLX (model unload time).
- **`ProcessType`** — `Standard` for brain (primary service), `Background`
  for MLX/Ollama (worker sidecars).
- **`EnvironmentVariables`** — `PATH` set in plist so the service is immune
  to shell profile changes or missing login context.
- **`SoftResourceLimits`** — `NumberOfFiles` 4096 to prevent file descriptor
  exhaustion.

### MLX-specific additions

- **`Nice`** — 5 (low priority) to avoid UI jank on interactive Mac use.
- **`WorkingDirectory`** — `${INSTALL_DIR}/runtime` for predictable
  relative path resolution by `mlx_lm.server`.

### run-mlx.sh changes

- Added `log_exit()` function and `trap log_exit EXIT` to record exit code
  and signal name to stderr on termination, aiding post-mortem diagnosis.
- Changed heredoc to single-quoted delimiter (`'RUNMLX'`) for cleaner
  runtime variable handling.

### run-ollama.sh changes

- Changed heredoc to single-quoted delimiter (`'RUNOLLAMA'`) for cleaner
  runtime variable handling (no behavioral change).
