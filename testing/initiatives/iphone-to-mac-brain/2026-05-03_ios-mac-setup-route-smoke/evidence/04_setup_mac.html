iHN Home on iPhone

Set up this Mac as your home brain

This page is served by the iHN Home app running on iphone. Start here when your iPhone is the first node and you want an M-series Mac to become the always-on iHomeNerd brain.

Trusted handoff

The setup begins from the App Store iPhone app and this local page. The Mac still needs normal macOS trust: a Mac App Store app or a Developer ID signed and notarized installer.

Home CA SHA-256 50:67:99:18 … 0F:16:3F:D5

Implementation status

The iPhone concierge surface is live. Pairing approval, one-time token handoff, and the signed/notarized Mac installer are next. This page intentionally does not expose the Home CA private key.

Developer preview

For source-tree testing only, the future Mac installer path will use these environment switches for native MLX:

curl -fsSL https://raw.githubusercontent.com/llm-case-studies/iHomeNerd/main/install-ihomenerd-macos.sh -o /tmp/install-ihomenerd-macos.sh
IHN_MAC_LLM_BACKEND=mlx IHN_MLX_MODEL=mlx-community/gemma-4-e2b-it-4bit IHN_SETUP_SOURCE_URL=http://192.168.0.220:17778 bash /tmp/install-ihomenerd-macos.sh
